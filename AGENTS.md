## Agent 自我更新规范 (Core Directive)

- **核心要求**：作为 AI Agent，每当你根据用户要求完成了新功能的开发、重构了代码逻辑、调整了目录结构、引入了新的库，或者更改了项目构建/测试命令后，**你必须主动且自动地编辑并更新本 `AGENTS.md` 文件**。
- 请将最新的项目认知（如新增的文件模块、新的常用命令、新确立的代码规范）就地更新（Improve in place）到此文件中，以确保下一个会话能够准确继承这些最新成果。
- 如果某次改动不涉及架构或规范层面的变化，则无需更新。

## Build

- `zig build` — compile (Zig >= 0.16.0
- `zig build run` — build + run (kills running game.exe first, Windows-only)
- `zig build test` — unit tests on `exe_mod` (transitive tests from `src/main.zig`)
- `zig build -Dtracy_enable=true` — enable Tracy; `-Dtracy_callstack=N` (default 10)
- Default target ABI is forced to `.gnu` (`build.zig:7`)
- `genFileNameIdHashMap` auto-runs as a build dep → regenerates `src/fileSystem/fileNameID.zig`. Do not edit by hand.

## Content pipeline (watcher)

The main workflow uses the **watcher** binary (`watcher/`, its own `build.zig`, Zig >= 0.16.0). It hot-reloads on file change:

- `zig build run` (from `watcher/`) starts the watcher
- It reads `.watching` to know which dirs to watch (`Shaders`, `Sampler`, `pipeline`, `zig-out\bin\Content`)
- On change, it automatically:
  - Compiles GLSL → SPIR-V (uses embedded `shaderc_combined`, no external `glslc` needed)
  - Re-parses affected pipeline `.pipe` files → `.pipeb` (traverses shader-pipeline graph in DB)
  - Parses sampler `.samp` files → `.sampler`
  - Updates content DB (`Content.db`) for files in `Content/` folder
- Ctrl+C exits, Ctrl+Break force-saves DB without exiting
- `-force` flag re-processes everything from scratch

The batch scripts in `build_script/` (`shaderCompile.bat`, `pipelineParse.bat`, `samplerParse.bat`) are the **manual fallback** — they need `glslc.exe` on PATH and a file list generated by `selectModifiedFileToTxt`.

## External prerequisites

- **Vulkan SDK** — headers in `include/vulkan/`, `lib/vulkan-1.lib` pre-bundled, but SDK still needed at runtime
- **Steam SDK** — `lib/steam_api64.lib` and DLL, headers in `include/steam/`
- **Python** — required for `build_script/pipelineConfig.py` and `feather_lut.py`
- SDL3, cglm, Tracy, meshoptimizer, blake3, shaderc — all built from source in `dependencies/`

## Architecture

- **Entrypoint**: `src/main.zig` spawns update + render threads, inits SDL3 + Vulkan + Tracy
- **Module convention**: Each significant source file is its own Zig module in `build.zig`. Import by module name (e.g. `@import("video")`, `@import("fileSystem")`), not file path
- **Vulkan core**: `src/video/VkStruct.zig` (~1850 lines) — device/swapchain/descriptors/gfx pipeline. `src/video/processRender.zig` — per-frame rendering
- **Render graph**: DAG-based pass system in `src/pass/` (`PassImp.zig`, `renderFlow.zig`). DAG debug flags in `src/global.zig` (`printDagToDot`, `stopNodeDagPrint`)
- **ECS**: `src/ecs.zig` (thin wrapper over `src/ecs/`)
- **Content DB**: SQLite database (`Content.db`) tracking all assets — managed by the watcher at dev time, read by the engine at runtime
- **Handle system**: `src/handle/handle.zig` — 10240 handles with `Once` reuse

## Ignored / special directories

- `config/` — gitignored; runtime config (pipeline push constants JSON)
- `testFeature/` — gitignored; ad-hoc test programs, NOT part of `zig build test`
- `.watching` — text file listing dirs the watcher monitors (one per line)
- `cache.json` — root level, content hash cache for `selectModifiedFileToTxt`
- `.zig-cache/`, `zig-out/`, `zig-pkg/` — build artifacts
